# 📦 Inventory Analysis

## Project Overview

This project explores how inventory data can be used to reduce excess stock, prevent stockouts, and improve inventory planning.

## Business Problem

Businesses need to maintain enough stock to meet demand without tying up unnecessary capital in excess inventory. This project will explore how data-driven inventory techniques can support better replenishment decisions.

## Objectives

- Classify inventory using ABC analysis.
- Calculate safety stock and reorder points.
- Identify items at risk of stockouts.
- Explore optimal order quantities using EOQ.
- Recommend practical inventory control measures.

## Tools

- Microsoft Excel
- Sample inventory dataset

## Methodology

1. Prepare and clean the inventory dataset.
2. Calculate annual consumption value for each item.
3. Perform ABC classification.
4. Calculate safety stock and reorder points using stated assumptions.
5. Analyze the results and develop recommendations.
